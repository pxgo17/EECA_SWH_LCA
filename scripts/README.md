# Power dispatch model, results processing and data integration 

This folder contains r and python scripts to implement power dispatch model, integrate operational and embodied results, and generate visualisations for final report.

## How to Use

energy_model/: Two python scripts to generate power dispatch series for different scenarios and to process associated results.
results_processing/: R scripts and notebooks to perform integration of operational and embodied analysis. Also includes notebook with some visualisations used for final report.
