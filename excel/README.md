# Supporting excel spreadsheets for EECA SWH LCA embodied emissions 

This folder contains excel spreadsheets supporting the calculation of embodied emissions components. 

## How to Use

Multiple versions available.
Latest file names are:

aggregate_peak_embedded_method.xlsx: Provides supporting data and method for the estimation of peak power reduction and associated saving in power infrastructure emissions.

SWH_capacity_formatting_23-09-2025_sensitivity_energy.xlsx: Provides supporting data and method for the calculation of SWH technologies Manufacture, Transportation (Distribution), Installation, EOL, and B2-B5 (Other) embodied emissions. 'Results' sheet is later used for data integration/aggregation to deliver estimates on a per household type basis. This dataset also includes latest data extracted from 'appliance_embodied_emissions_energy250925.xlsx' series.
